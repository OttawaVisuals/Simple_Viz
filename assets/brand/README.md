# Made Clear brand kit

## Quick picks

- Website/vector: `madeclear-lockup-light.svg` or `madeclear-lockup-dark.svg`
- Email signature: `madeclear-email-signature-light.png`
- Reddit/social avatar: `madeclear-social-light-1024.png`
- Favicon: `favicon.ico` or `favicon.svg`
- Transparent symbol: `madeclear-mark-transparent-512.png`

## Colours

| Role | Light | Dark |
|---|---|---|
| Background | `#F7F5F0` | `#121A2C` |
| Foreground | `#1B1A17` | `#E9E6DB` |
| Accent | `#2F6BD8` | `#6FA0F2` |

## Usage

- Keep clear space around the logo equal to roughly the height of the lowercase `c`.
- Use the square mark for favicons and avatars.
- Use the horizontal lockup for headers and signatures.
- Do not stretch, rotate, add shadows, or change the signal line independently.
- SVG files use Georgia/scientific italic with system fallbacks. PNG exports lock in the Windows Georgia rendering.

## Rebuild PNG exports

Run `build_brand.py` with Python and Pillow installed.
